# Heffte.jl

Heffte.jl provides Julia bindings to the Highly Efficient FFT for Exascale
(HeFFTe) library. HeFFTe is designed for the efficient computation of Fast
Fourier Transforms (FFT) on large-scale parallel systems. This package enables
the use of HeFFTe's capabilities within the Julia programming environment,
facilitating high-performance FFT operations in Julia-based applications.
